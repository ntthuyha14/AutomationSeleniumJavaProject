# Automation Selenium Java Project

A comprehensive test automation framework built with Selenium WebDriver and Java for automating web application testing.

## Table of Contents

- [Project Overview](#project-overview)
- [Technology Stack](#technology-stack)

## Project Overview

This project is a Selenium WebDriver-based test automation framework written in Java. It's designed to support automated testing of web applications with a focus on maintainability, scalability, and ease of use.

**Key Features:**
- 90.7% Java codebase with 9.3% HTML (test data)
- Maven-based project management
- TestNG test framework integration
- Organized test case structure
- Screenshot capture capabilities
- Centralized test reporting

## Technology Stack

| Technology | Version | Purpose |
